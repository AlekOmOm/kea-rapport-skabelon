# Product Backlog Template

## Prioritering
Prioritér jeres user stories baseret på:
1. Minimumskrav fra opgavebeskrivelsen
2. Værdi for interessenter
3. Teknisk kompleksitet
4. Afhængigheder mellem user stories

## Format for User Stories

```
Som [rolle] vil jeg [handling/funktionalitet], så [formål/værdi].

Acceptkriterier:
1. Given [forudsætning], When [handling], Then [forventet resultat].
2. Given [forudsætning], When [handling], Then [forventet resultat].
...

Estimat: [Story Points/Tid]
MoSCoW: [Must have / Should have / Could have / Won't have]
```
